3. Datos Personales que Recopilamos

📝 Datos de Identificación

  • Nombres y apellidos completos
  • DNI o documento de identidad
  • Fecha de nacimiento
  • Firma autógrafa

📍 Datos de Contacto

  • Dirección de correo electrónico
  • Números de teléfono
  • Dirección de domicilio
  • Dirección de entrega

💳 Datos Transaccionales

  • Historial de compras
  • Preferencias de productos
  • Métodos de pago (sin almacenar datos sensibles)
  • Comentarios y valoraciones

🩺 Datos de Salud (con consentimiento)

  • Información de alergias
  • Medicamentos de uso frecuente
  • Condiciones médicas relevantes
  • Preferencias de productos médicos

5. Sus Derechos ARCO

Usted tiene derecho a ejercer los siguientes derechos sobre sus datos personales:

A

Acceso

Conocer qué datos personales tenemos de usted y cómo los estamos tratando.

R

Rectificación

Solicitar la corrección de sus datos personales si son inexactos o incompletos.

C

Cancelación

Solicitar la eliminación de sus datos personales cuando ya no sean necesarios.

O

Oposición

Oponerse al tratamiento de sus datos para fines específicos.

6. Transferencias Internacionales

Botica SAC no realiza transferencias internacionales de datos personales fuera del territorio peruano, a menos que sea estrictamente necesario para la prestación de servicios y se cuente con las garantías adecuadas exigidas por la normativa de protección de datos personal.

7. Medidas de Seguridad

🔐

Seguridad Técnica

Implementamos medidas de seguridad técnicas como encriptación, firewalls y controles de acceso.

👥

Seguridad Organizativa

Contamos con políticas internas y capacitación constante para nuestro personal.

📊

Auditorías Regulares

Realizamos auditorías periódicas para verificar el cumplimiento de nuestras medidas de seguridad.
